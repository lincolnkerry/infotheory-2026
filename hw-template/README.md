# HW#N — Introduction to Information Theory 2026

## How to submit
1. Put your solution in the `submission/` folder:
   - preferred: a single PDF (`submission/hwN.pdf`) — scanned handwriting is fine if legible;
   - or Markdown with LaTeX (`submission/hwN.md`).
2. If you worked as a group (max 3), list all members at the top of your solution.
   **Each member still submits in their own repository.**
3. `git add / commit / push` before **the deadline (23:59 KST)**. The last commit
   before the deadline is graded.

## What happens next
- The AI TA grades your work against the instructor's rubric,
  commits `feedback/hwN-feedback.md` (score + per-problem corrections) to this
  repository, and emails you a summary.
- Only you and the instructor can see this repository and your grade.
- Regrade request: open an issue in this repository within 7 days of feedback.
