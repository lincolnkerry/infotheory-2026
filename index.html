Homework Submission via GitHub

Every homework is due at 23:59 KST on a Wednesday — the end of Wednesday, not its beginning. Grading runs automatically at 00:10 the next morning, so corrections are back before the following Monday lecture. One repository for the whole semester. Register your GitHub username once in week 1; you are then invited to a private repository that holds every assignment. The AI grader reads your submission, commits per-problem corrections back to that same repository, and opens an issue that mentions you — so GitHub notifies you as soon as a score is posted. There is no second invitation and nothing to re-clone.

1 · Register

  1. Create a GitHub account if you do not have one. Any username is fine.
  2. Write your username next to your student ID in the registration sheet. Do this in week 1 — no username means no repository, and no way to submit.
  3. Accept the emailed invitation to it2026-<your-username>.

2 · Submit

  1. All ten problem sheets are already in problems/ in your repository.
  2. Put your solution in submission/hwN.pdf — exactly that name, N being the assignment number. A file named anything else is not found, and counts as missing.
  3. PDF (scanned handwriting is fine if legible) or Markdown. Deadlines are always Wednesday 23:59 KST; the last commit before that moment is the one graded.

3 · Feedback

  1. Per-problem scores and corrections appear as feedback/hwN-feedback.md.
  2. An issue titled HW#N graded: score/100 is opened and mentions you.
  3. Regrade requests: reply in that issue within 3 days. No email needed.
